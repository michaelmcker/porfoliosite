# Marketing Engineering Field Notes source

This directory contains only articles that are eligible for the public repository. Private weekly evidence, briefs, approvals, drafts, gate reports, and publication receipts live under `~/.codex/automations/weekly-field-notes/state/` and must never be copied here.

An entry is renderable only when its front matter declares `status: published`. The Sunday workflow may create that source only after the exact Saturday brief approval remains valid and every blocking gate passes.

The renderer accepts a deliberately small Markdown subset and rejects raw HTML. Public entries contain no external quotations in version one.
